# Ответы на вопросы к зачету по экономике

## 1. Процентная ставка

### Определения



| Термин                    | Определение                                                  |
| ------------------------- | ------------------------------------------------------------ |
| **Процентная ставка (i)** | Отношение процентов за год к сумме ссуды                     |
| **Ссуда (P)**             | Передача денег или иных материальных ценностей одним участником договора другому на условиях возврата и обычно с выплатой процентов |
| **Доход от ссуды (I)**    | Абсолютная величина денежных средств от предоставления их в долг (может иметь любую форму) |
| **Наращенная сумма (S)**  | Сумма ссуды и дохода: **S = P + I**                          |

### Виды процентных ставок



| №    | Вид ставки    | Обозначение | Характеристика                                               |
| ---- | ------------- | ----------- | ------------------------------------------------------------ |
| 1    | Простая       | i           | База начислений остается постоянной                          |
| 2    | Сложная       | i*          | База начисления является переменной                          |
| 3    | Номинальная   | j           | Годовая ставка при переменном начислении                     |
| 4    | Сила роста    | δ           | Процентная ставка при непрерывном начислении                 |
| 5    | Эквивалентные | —           | Две любые ставки, дающие одинаковый результат при замене одной на другую |
| 6    | Брутто-ставка | r           | Ставка с учетом инфляции                                     |

### Формулы расчёта

**Простая процентная ставка:**

- Наращенная сумма: **S = P(1 + ni)**
- Срок ссуды: **n = t/k** (t — число дней ссуды, k — число дней в году)
- Вычисление n: **n = (S/P) − 1**
- Вычисление i: **i = (S/P − 1) / n**

**Сложная процентная ставка:**

- Наращенная сумма: **S = P(1 + i\*)ⁿ**
- Вычисление n: **n = ln(S/P) / ln(1 + i\*)**
- Вычисление i*: **i\* = (S/P)^(1/n) − 1**

**Номинальная процентная ставка:**

- Формула: **S = P(1 + j/m)ᵐⁿ**
- m — количество начислений за период (квартал: m=4, полгода: m=2)

**Сила роста (непрерывное начисление):**

- Формула: **S = Pe^(δn)**

**Эквивалентность ставок:**

1. Простой и сложной: **1 + ni = (1 + i\*)ⁿ**
2. Сложной и номинальной: **(1 + i\*)ⁿ = (1 + j/m)ᵐⁿ**
3. Эффективная ставка: **i\* = (1 + j/m)^m − 1**

**Брутто-ставка с учётом инфляции:**

- **r = i + инфляционная премия**
- Реальная стоимость денег: **C = P / Iₚ**, где Iₚ — индекс цен
- Индекс цен: **Iₚ = (1 + H)ⁿ**, где H — темп инфляции

### Кросс-курс

**Определение:** Обмен между двумя валютами через третью валюту

**Методы расчёта:**



| Тип                       | Формула               | Условие                                    |
| ------------------------- | --------------------- | ------------------------------------------ |

| **Через несколько валют** | A/B = A/C × C/D × D/B | Используется несколько промежуточных валют |

## 3. Погашение задолженностей

### Основные определения

- **Задолженность** — состоит из основной суммы долга и начисленных процентов
- **Рента** — задолженность, получаемая с должника
- **Контур платежей** — графическое представление выплат (должен быть замкнутым, остаток долга = 0)

### Виды ренты



| Критерий              | Виды                                                         |
| --------------------- | ------------------------------------------------------------ |
| **По источнику**      | Экономическая (аренда земли, денег, ИС), Рыночная (зависит от ситуации на рынке) |
| **По сроку**          | Временная (долгосрочная >1 года, краткосрочная), Пожизненная, Постоянная, Вечная |
| **По моменту выплат** | Постнумерандо (в конце периода), Пренумерандо (в начале периода), В середине периода, m-срочные |
| **По виду платежа**   | Аннуитетная, Дифференцированная                              |

### Виды платежей

#### Аннуитетные платежи

**Характеристика:** Выплаты равными платежами за каждый период (кроме последнего). Одновременно гасятся сумма основного долга и начисленные проценты. Чем больше сумма долга, тем больше процентов гасится в первую очередь.

**Формула ежемесячного платежа:**

```
1
```

#### Дифференцированные платежи

**Характеристика:** Ежемесячные платежи, уменьшающиеся к концу срока. Уменьшаются только проценты, а ежемесячная сумма основного долга остается постоянной.

**Формула ежемесячного платежа:**

```

```

## 4. Дисконтирование

### Определение

**Дисконтирование** — действие, обратное наращиванию, приведение будущей стоимости денег к текущей.

### Формулы дисконтирования



| Тип                     | Формула наращивания | Формула дисконтирования |
| ----------------------- | ------------------- | ----------------------- |
| **Без капитализации**   | S = P(1 + ni)       | P = S/(1 + ni)          |
| **С капитализацией**    | S = P(1 + i*)ⁿ      | P = S/(1 + i*)ⁿ         |
| **Со ставкой дисконта** | —                   | P = S/(1 + d)ᵗ          |

**Сумма дисконта при сроке более 1 года:**

```
1
```

### Ставка дисконтирования

**Определение:** Показатель, позволяющий оценить доходность будущих инвестиций.

#### Факторы, влияющие на ставку дисконтирования



| №    | Фактор                                    | Влияние                                                      |
| ---- | ----------------------------------------- | ------------------------------------------------------------ |
| 1    | Качество актива/проекта                   | Ликвидность, размер предприятия, стадия жизненного цикла     |
| 2    | Продолжительность периода прогнозирования | Чем больше период, тем ставка выше                           |
| 3    | Валютный фактор                           | При работе с иностранной валютой ставка берётся максимальной |
| 4    | Инфляционные ожидания                     | Чем меньше ожидания, тем ставка меньше                       |
| 5    | Ключевая ставка Центробанка               | Прямое влияние                                               |

#### Жизненный цикл предприятия и ставка дисконтирования



| Стадия     | Ставка дисконтирования |
| ---------- | ---------------------- |
| Зарождение | Большая                |
| Рост       | Уменьшается            |
| Зрелость   | Маленькая              |
| Спад       | Максимальная           |

#### Методы расчета ставки дисконтирования



| №    | Метод                        | Описание                                                     |
| ---- | ---------------------------- | ------------------------------------------------------------ |
| 1    | **Метод безрисковой ставки** | Определение по самым надёжным инструментам для минимизации рисков |
| 2    | **Интуитивный метод**        | Сумма безрисковой ставки и размера инфляции                  |
| 3    | **Метод экспертной оценки**  | Голосование экспертов-инвесторов + премия за риск: • Риск масштаба бизнеса (0-5%) • Специфический риск (0-5%) • Риск перехода от гос. к частному (0-30%) |
| 4    | **Метод рентабельности**     | На основе активов или собственного капитала предприятия      |

**Формулы рентабельности:**

- **ROE** (собственного капитала) = (Чистая прибыль / Собственный капитал) × 100%
- **ROA** (активов) = (Чистая прибыль / ((Анп + Акп)/2)) × 100%

### Инвестиции

#### Определение

**Инвестиции** — размещение капитала с целью получения прибыли.

#### Что является инвестициями:

- Денежные средства
- Целевые банковские вклады
- Ценные бумаги
- Технологии, машины, оборудование
- Лицензии (в том числе на товарные знаки)
- Кредиты
- Имущественные и неимущественные права
- Интеллектуальные ценности

#### Признаки инвестиций:

1. Потенциальная способность приносить доход
2. Определённый срок вложения средств
3. Целенаправленный характер вложения капитала
4. Использование разных инвестиционных ресурсов
5. Наличие риска вложения капитала

#### Виды инвестиций:



| Категория                | Виды                                                         |
| ------------------------ | ------------------------------------------------------------ |
| **По типу**              | Финансовые (ценные бумаги, активы других организаций), Капиталообразующие/реальные (основной и оборотный капитал) |
| **По объектам**          | Реальные, Финансовые (портфельные), В нематериальные активы  |
| **По собственности**     | Частные, Государственные (~10%), Иностранные, Совместные     |
| **По продолжительности** | Краткосрочные (до 1 года), Среднесрочные (1-3 года), Долгосрочные (>3 лет) |
| **По риску**             | Низкая, Средняя степень риска                                |
| **По жизненному циклу**  | Начальные, Экстенсивные, Реинвестиции                        |
| **По назначению**        | Повышение эффективности, Расширение/диверсификация, Создание новых производств, Обеспечение выживания, Гос. заказы, Требования закона |
| **По участию**           | Прямые (первичное размещение), Косвенные (вторичный рынок, ПИФы) |

#### Источники финансирования:

- По числу источников: один или несколько
- По местоположению: внутренние и внешние
- По принадлежности капитала: собственные, привлечённые, заёмные

### Инвестиционный менеджмент

**Определение:** Вид деятельности, направленный на исследование, анализ, регулирование инвестиционного рынка, его организацию и планирование.

#### Задачи инвестиционного менеджмента:



| №    | Задача                                                       |
| ---- | ------------------------------------------------------------ |
| 1    | Анализ, выбор и оценка инвестиционных объектов с учётом риска и доходности |
| 2    | Обеспечение роста экономического и производственного роста предприятия |
| 3    | Максимизация доходности                                      |
| 4    | Минимизация рисков                                           |
| 5    | Обеспечение финансовой устойчивости и платёжеспособности     |
| 6    | Своевременная реализация инвестиционной программы            |

#### Функции инвестиционного менеджмента:



| №    | Функция          | Описание                                                   |
| ---- | ---------------- | ---------------------------------------------------------- |
| 1    | **Планирование** | Разработка стратегии                                       |
| 2    | **Организация**  | Осуществление инвестиций, описание потребности в средствах |
| 3    | **Мотивация**    | Заинтересованность исполнителей проекта в результате       |
| 4    | **Контроль**     | Сравнение плана с реальностью                              |

### Факторы, влияющие на инвестиционную привлекательность предприятия:

1. Характеристика технической базы (оборудование)
2. Номенклатура выпускаемой продукции
3. Производственная мощность
4. Место предприятия в отрасли на рынке
5. Характеристика системы управления
6. Уставной капитал
7. Структура затрат на производство
8. Объем прибыли и направления её использования
9. Оценка финансового состояния предприятия

### Этапы принятия инвестиционных решений:

1. Определить размер инвестиций и источников финансирования
2. Оценка предполагаемых денежных потоков от реализации проекта
3. Оценка финансового состояния и шансов участия в инвестиционной деятельности

### Методы оценки эффективности инвестиций

#### Статистические методы (без дисконтирования):



| Показатель                      | Формула                                                 | Критерий              |
| ------------------------------- | ------------------------------------------------------- | --------------------- |
| **Срок окупаемости (PP)**       | PP = t, при котором ΣSᵢ > P                             | Чем меньше, тем лучше |
| **Простая норма прибыли (ARR)** | ARR = Средняя чистая прибыль / Средний объём инвестиций | Чем больше, тем лучше |

#### Динамические методы (с дисконтированием):



| Показатель                                | Формула                               | Критерий принятия               |
| ----------------------------------------- | ------------------------------------- | ------------------------------- |
| **Чистая приведённая стоимость (NPV)**    | NPV = Σ(Sᵢ/(1+d)ⁱ) − P                | > 0 — принять, < 0 — отвергнуть |
| **Внутренняя норма доходности (IRR)**     | IRR = d, при котором NPV = 0          | > d — принять, < d — отвергнуть |
| **Дисконтируемый срок окупаемости (DPP)** | DPP = t, при котором Σ(Sᵢ/(1+d)ⁱ) ≥ P | Чем меньше, тем лучше           |
| **Индекс рентабельности (PI)**            | PI = Σ(Sᵢ/(1+d)ⁱ) / P                 | > 1 — принять, < 1 — отвергнуть |
